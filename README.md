# NLP (자연어처리)
### 2024512044 인공지능융합학과 박민선 

#### [과제 선정의 이유 및 과제 진행 방향] 
한국의 공공문서 및 기업문서에서 많이 사용되는 HWP 파일 형식은 파싱이 어렵다는 문제를 가지고 있습니다. 이에, pdf로 변환 후 전처리를 하는 경우도 있었습니다. 이에 Java 기반 라이브러리인 hwplib와 hwpxlib를 Python에서 활용하여 HWP 파일을 파싱하고자합니다. 그리고 정규화, 불용어 제거 등 수업시간 중 배운 nlp 내용을 토대로 추출된 텍스트에 대해 다양한 방법을 통해 시각화 및 정보를 추출하고자 합니다. 
마지막으로, OpenAI API를 활용하여 문서 기반 질의응답 시스템을 구현했습니다.



#### [주요기능] 

1. HWPX 파일 파싱
- Java 기반 라이브러리인 hwpxlib을 JPype를 통해 Python에서 활용
- 한글 문서에서 텍스트를 추출하여 분석 가능한 형태로 변환

2. 텍스트 기반 분석
- 단어 빈도 분석: 문서에서 가장 많이 등장하는 단어 분석
- 정규표현식 패턴 검색: 특정 패턴을 가진 단어 추출 (예: '상속'으로 시작하는 단어)
- 공기어(연관어) 분석: 함께 등장하는 단어 패턴 분석
- 문맥 검색: 특정 키워드가 등장하는 문맥 분석

3. RAG(Retrieval-Augmented Generation) 시스템 구현
- 문서 청킹: 텍스트를 의미 있는 단위로 분할하여 검색 효율성 향상
- 키워드 기반 검색: 질문에서 추출한 키워드를 기반으로 관련 문서 청크 검색
- Claude API 활용: 검색된 관련 문서를 바탕으로 질문에 대한 정확한 답변 생성
- 프롬프트 엔지니어링: 법률 문서에 특화된 전문적인 답변을 위한 프롬프트 설계
